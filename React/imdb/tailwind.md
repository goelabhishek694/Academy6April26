# Tailwind CSS Notes

Tailwind CSS is a utility-first CSS framework that helps developers build modern,
responsive user interfaces quickly by composing small, reusable utility classes.

## Setup

This project uses Tailwind CSS with Vite. Follow the official setup guide:

[Install Tailwind CSS with Vite](https://tailwindcss.com/docs/installation/using-vite)

## Features

### Utility-First Approach

Tailwind provides small, single-purpose utility classes that can be combined to
create complex layouts and designs. This makes styling faster, more reusable, and
easier to maintain.

### Customizable Design System

Tailwind can be customized to match a project's design requirements, including
colors, spacing, typography, breakpoints, and other design tokens.

### Responsive Design

Tailwind includes responsive variants for utility classes, making it easy to
build layouts that adapt to different screen sizes and devices.

### Performance Optimized

Tailwind generates optimized CSS by including only the styles used in the
project, which helps keep CSS file sizes smaller and improves page loading
performance.

### Active Community

Tailwind has a large community, strong documentation, and a growing ecosystem of
plugins and tools that make it useful for many types of web development projects.

## Homework

Build a simple React app with navigation using React Router DOM.

### Requirements

- Create a navigation bar with two links:
  - `Home`
  - `Watchlist`
- Create two React components:
  - `Home`
  - `Watchlist`
- Render the `Home` component when the user clicks the `Home` link.
- Render the `Watchlist` component when the user clicks the `Watchlist` link.
- Use `react-router-dom` to handle routing between both pages.
